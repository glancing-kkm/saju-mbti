# 동양화 이미지 세트

2026-10-20 · built-in `image_gen`으로 제작했어요.

한지 질감, 섬세한 먹선, 담채와 광물 안료의 색감을 공통으로 사용해요. 인물은 한복을 입은 20대 한국인 남녀로 표현했어요.

- `posters/`: 카테고리 원화 31종과 홈 타로 미리보기용 덱 이미지
- `tarot/`: 메이저 22장, 완드·컵·소드·펜타클 각 14장, 공통 뒷면
- `og-image.jpg`: 공유 대표 이미지
- `poster-prompts.json`, `tarot-prompts.json`: 그림별 제작 프롬프트
- `extras-prompts.json`: 카드 뒷면과 공유 이미지 프롬프트

웹용 WebP로 최적화했어요. 카테고리는 긴 변 1,000px, 타로는 900px이며 원화 PNG는 생성 도구의 기본 저장 위치에 보관돼요. 홈의 타로 미리보기는 실제 덱과 같은 그림을 사용해요.

타로 파일 순서는 카드 데이터와 동일해요: 01–22 메이저, 23–36 완드, 37–50 컵, 51–64 소드, 65–78 펜타클. 카드의 이름과 정방향·역방향 표시는 화면의 텍스트로 제공해요.
