콘텐츠 작성 기준

최종 업데이트 2026-06-27 ·버전 1.0

천지인 사주의 콘텐츠는 사용자가 자신의 성향과 흐름을 이해하도록 돕기 위한 참고 정보예요. 계산 가능한 사주 구조, 전통 명리 해석, 사용자 입력 정보를 바탕으로 만들며, 불안감을 자극하거나 특정 결정을 강요하지 않습니다.

1. 원본 계산과 해석의 분리

사주판, 다섯 기운 분포, 태어난 계절, 관계 흐름 같은 기본 정보는 입력값을 바탕으로 계산합니다. 이후 풀이 문장은 계산된 구조를 사용자가 이해하기 쉬운 말로 바꾸어 설명해요.

계산 결과와 해석 문장을 분리해 관리하기 때문에, 단순한 복사 콘텐츠나 의미 없는 자동 조합이 되지 않도록 점검합니다.

2. AI 활용 범위

인생총운, 신년운세, 즉문즉답 일부에는 AI가 활용될 수 있습니다. AI는 계산된 사주 구조와 사용자가 입력한 질문을 바탕으로 문장을 정리하고, 더 자연스러운 상담형 답변을 만드는 데 사용됩니다.

  • AI 답변은 사주 계산 결과를 대체하지 않고 보완합니다.
  • 출생 정보와 질문 내용 외의 불필요한 민감 정보 입력을 권하지 않습니다.
  • 의료·법률·투자 판단처럼 전문 자격이 필요한 영역은 참고 의견으로만 안내합니다.
  • 불필요하게 공포를 조장하거나 사용자의 판단을 빼앗는 표현은 사용하지 않습니다.

3. 얇은 콘텐츠를 피하는 기준

블로그와 해설 페이지는 사주 용어를 단순 나열하지 않고, 의미·보는 방법·현실 적용 예시를 함께 담는 것을 기준으로 합니다. 비슷한 문장을 여러 페이지에 반복하기보다, 각 주제에 맞는 설명과 예시를 추가해 사용자가 얻어 갈 내용이 있도록 관리합니다.

4. 광고와 결제 안내

광고는 콘텐츠와 구분되도록 배치하고, 사용자가 광고를 서비스 버튼이나 결제 버튼으로 오해하지 않도록 관리합니다. 결제 상품은 가격, 제공 내용, 환불 기준을 결제 전 확인할 수 있게 안내합니다.

5. 사용자 보호 원칙

  • 수명, 사망 시기, 질병 결과를 단정하지 않습니다.
  • 건강운은 예방과 관리 관점으로만 설명합니다.
  • 투자 종목, 법적 판단, 치료 방법을 확정적으로 지시하지 않습니다.
  • 타인에 대한 혐오, 보복, 차별을 부추기지 않습니다.
  • 미성년자에게 부적절한 결제 유도나 자극적인 표현을 사용하지 않습니다.

6. 오류 제보와 수정

계산 오류, 오탈자, 부적절한 표현, 결제 오류를 발견하시면 na37zzang@gmail.com으로 알려 주세요. 확인 후 필요한 경우 콘텐츠를 수정하고, 결제 오류는 결제·환불 정책에 따라 처리합니다.
