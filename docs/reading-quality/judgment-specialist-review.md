# 판단 근거·주제 상품 차별화·분량 검토 (2026-11-05)

> 후속 요청으로 권장 웹 분량도 코드에 적용했습니다. 아래는 적용 전 비교 기록입니다. 최신 상태는 [웹 분량 적용](web-length-policy.md)을 참고하세요.

## 적용 범위와 상태

이번 작업은 해석·편집 단계의 고도화입니다. 사주 만세력, 대운·세운·월운, 카드 추출, 행성/명반 계산, 상품 가격과 결제 로직은 변경하지 않았습니다. 무료 풀이에 AI 호출을 추가하지 않았습니다. 운영 웹 분량 기본값은 100%로 유지했습니다. 짧은 구성은 비교용 도구에서만 사용합니다. GitHub 푸시·운영 배포는 수행하지 않았습니다.

## 구현

- `assets/ai-report.js`: 실제 근거 ID를 지지/반대/시기별로 연결하는 판단표 검증, 장별 판단 배정, 장이 새로 제공할 내용(`newContribution`) 필수화, 문장 중복 진단, 구체적인 오류 수정 피드백. 기존 판단표 v1/기존 형식은 호환됩니다.
- `worker/saju-chat-worker.js`: 11개 주제별 독립 질문·상담 가치와 점술별 근거 정책. 유료 사주·타로·점성술·자미두수·이름풀이/PDF 집필에 적용되는 공통 상담 초점입니다. 설계 단계에서 근거 비교와 장 역할을 먼저 작성하며, 새 AI 호출 단계를 추가하지 않았습니다. 판단표를 쓰는 설계 단계만 reasoning medium, 기존 본문 effort 정책은 유지합니다.
- 장별 역할 예: 재물은 수입원/변동성/순이익/지출/공동 자금/유동성/기간별 선택, 연애는 시작/표현/신뢰/갈등/친밀감/현재 관계. 총운은 전체 균형, 신년은 해당 연도 변화에 답합니다. 독립 상품을 총운 요약의 단순 확장으로 쓰지 않게 했습니다.
- 대운 회고 장이 요약해야 할 실제 과거 대운 근거를 배정했습니다. 시간 미상의 대운 시작 경계는 웹/PDF 시작에 참고 범위임을 알리고, 장마다 같은 주의 문구를 반복하도록 강제하지 않습니다. 확정적 시각 단정은 계속 검사합니다.
- 중복 진단은 긴 동일·유사 문장을 찾는 보조 장치입니다. 서로 다른 연도는 같은 문장으로 합치지 않습니다. 의미가 비슷하다는 이유로 필요한 시기별 설명을 무조건 삭제하거나 새로운 재생성 반복을 추가하지 않습니다.

## 실제 모델 생성 검토

가상의 출생정보, 개발용 카드/차트를 사용했습니다. 주문·실사용자 저장소에 쓰지 않는 임시 Worker에서 실제 모델 호출로 생성했습니다. 생성 표본은 점술의 예측 정확성을 입증하지 않으며, 명리 전문가 검수를 받았다는 의미도 아닙니다.

| 구분 | 건수 | 확인 범위 |
|---|---:|---|
| 다양한 연령·명식의 인생총운/신년 | 10 | 16/24/39/55/70세, 시간 미상 포함, 판단표 v1 |
| 별도 재물/연애 상품 | 2 | 동일 명식의 총운과 비교, 판단표 v1 |
| 짧은 구성 2차 비교 | 4 | compact와 concise 각 총운/신년, 판단표 v1 |
| 장별 새 내용 설계를 추가한 재물/연애 | 2 | 최신 판단표 v2, 서버 전달과 실제 집필 |
| 타로 | 2 | 같은 세 카드/방향, 재물과 연애의 질문 차이 |
| 점성술 | 2 | 같은 계산 차트, 직업과 연애의 질문 차이 |

구조화 리포트 18건은 최종 코드로 다시 검사하여 모두 통과했습니다. 타로/점성술 4건은 각 기존 본문 검사에 통과했습니다. 긴 문장 중복 진단은 0건이었으나, **같은 의미의 반복이 완전히 없다는 판정은 아닙니다.** 특히 재물에서 수입과 관리의 공통 주제가 여러 장에 남았습니다. 이를 보고 v2에서 장별 새 정보/비교/판단 기준을 필수로 추가했습니다. 최신 두 원고도 실제 생성해 통과를 확인했지만, 의미 중복과 읽는 재미에는 사람의 후속 검토가 필요합니다.

기존 코드로 생성한 별도 기준 표본 1건은 기존 원국 불일치 검사에서 완성되지 않았습니다. 성공 사례로 포함하거나 기존 대비 속도 향상의 기준으로 쓰지 않았습니다.

## 실제 분량 비교와 권장값

아래 글자 수는 마크다운 본문 paragraph 문자열의 합입니다. 화면 헤더·차트·표·고정 UI는 제외합니다. 두 쌍은 각각 같은 가상 명식·나이·상품을 사용했지만 생성은 확률적이며 원문 편집이 아닌 새 생성입니다.

| 상품 | 기존 장 구조의 실제 본문 | 통합 구성의 실제 본문 | 실제 비율 |
|---|---:|---:|---:|
| 인생총운 | 22장 / 14,315자 | 10장 / 6,824자 | 47.7% |
| 신년운세 | 27장 / 14,762자 | 12장 / 8,628자 | 58.4% |

분량 지시만 65~70%로 바꾼 표본은 여전히 13,000~15,500자로 길었습니다. **숫자 지시보다 중복 챕터 통합이 효과적**이었습니다. 통합판도 미래 10개 연도, 해당 12개 월운, 실제 대운 자료를 사용하며 필수 기간 누락 검사를 통과했습니다. 다만 총운의 독립 성향 장을 합치는 만큼 비교 원고를 읽고 선호를 정하는 단계가 필요합니다.

권장 운영 목표(아직 미적용):

| 상품 | 현재 대비 권장 본문 | 권장 분량과 방향 |
|---|---:|---|
| 사주 인생총운 | 60~65% | 약 8,500~9,500자. 짧은 실험판보다 성향/갈등 설명 여유 확보 |
| 사주 신년운세 | 60~70% | 약 9,000~10,000자. 12월운 유지, 총론/비교/마무리 중복 통합 |
| 독립 주제별 사주 | 75~85% | 상품에 따라 대략 5,000~8,000자. 재물·직업은 상단, 건강·간단 주제는 하단. 일률 할당 금지 |
| 유료 타로 | 90~100% | 기존 1,000~3,000자 범위 유지 중심. 카드 사전 설명을 조합 해석으로 교체 |
| 점성술 | 85~100% | 기존 1,200~3,600자 범위에서 주제 관련 실제 신호에 집중 |
| 자미두수·이름풀이 | 80~90% 후보 | 반복 구조를 줄이는 후보이며 실제 모델 축약 비교는 미실시 |
| PDF 심층판 | 깊이 유지 | 웹 결론에 이유·조건·선택 비교를 더함. 최대 60,000자, 분량 채우기 금지 |

주제별 최신 실제 생성은 재물 10,438자·연애 8,960자로 여전히 분량 지시를 초과했습니다. 75~85%는 **목표 추천**이지 현재 모델이 정확히 지킨다는 약속이 아닙니다. 적용하려면 도입/구조/결론의 겹치는 장을 합치는 구조 조정과 실제 재검토가 필요합니다. 타로/점성술은 이미 짧으므로 사주 총운과 같은 축소율을 적용하면 해석이 빈약해질 수 있습니다.

## 속도 판단의 한계

짧은 두 표본은 동시 2리포트/최대 4요청 임시 환경에서 각각 약 78초였습니다. 10초 완성을 검증한 것은 아닙니다. 기존 구조 표본에는 재시도·중단 후 재개 시간이 섞여 있어 전체 생성 지연을 직접 비교할 수 없습니다. 글자 수를 40% 줄였다고 시간이 40% 줄었다고 보고하지 않습니다. 장 수/출력량 감소는 개선 방향이지만 운영 조건에서 같은 입력·모델·동시성·캐시 미사용으로 반복 측정해야 합니다.

## 검증과 미검증

`npm test` 32개 검증 명령이 최종 실행에서 종료 코드 0으로 통과했습니다. 무료 AI 미사용, 기존 결제/24시간/기기 접근, PDF 웹기반 심화, 기간 누락, 원국 검증, 리포트 복구, 카드 의미 등 기존 회귀 테스트와 새 판단표 검사를 포함합니다. 결제·PDF 테스트의 모델/거래는 모의 응답이며 실제 결제나 실 PDF 출력 품질을 검증한 것은 아닙니다. 실제 모델 검토는 위 표본 범위입니다. 자미두수·이름의 실제 신규 AI 표본, 모든 상품의 전문가 심사, 운영 지연의 전후 반복 측정은 미실시입니다.

## 도구와 확인 파일

- `tools/judgment-specialist-regression.js`: 판단표·장 역할·서버 전달·기존 형식·근거/기간 및 PDF 불확실성 회귀 검사.
- `tools/run-judgment-pilot.js`: 기본은 비용 없는 분량 분석, `--live`에서만 임시 /generate 엔드포인트를 실제 호출. `--compact`, `--concise`, `--specialist-v2` 비교 지원. 운영 API의 결제 우회 경로가 아닙니다.
- `tools/lib/compact-review-outline.js`: 비교용 챕터 통합, 운영에서는 로드하지 않음.
- `tools/render-judgment-review.js`: 오프라인 비교 HTML 생성.
- `judgment-specialist-samples.html`: 실제 생성 원고와 판단표, 아직 점수를 매기지 않은 사람 검토 체크리스트.

배포할 경우 Worker를 먼저 배포하여 새 판단표 형식 수용을 확인하고 프런트를 배포합니다. 계산 엔진 롤백과는 무관한 해석 계층 변경입니다. 기존 완성본의 캐시 재사용/이전 판단표는 실제 운영 롤아웃에서도 별도로 확인해야 합니다.
