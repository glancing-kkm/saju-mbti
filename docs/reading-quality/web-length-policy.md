# 권장 웹 분량 적용

2026-11-05 후속 요청: 비교 샘플이 아닌 실제 생성 경로에 권장 분량을 적용합니다. 아직 GitHub 푸시/운영 배포는 하지 않았습니다.

| 상품 | 적용 목표 |
|---|---|
| 인생총운 | 기존 대비 약 62.5%, 본문 8,500~9,500자 |
| 신년운세 | 약 65%, 본문 9,000~10,000자 |
| 독립 주제별 사주 | 기존 상품별 목표/장별 지시의 80% |
| 이름풀이·자미두수 | 기존 장별 목표의 80% |
| 유료 타로 | 약 95%; 3장 1,000~1,500자, 5장 1,500~2,100자, 10장 2,100~3,000자 |
| 유료 점성술 | 약 90%; 총운 2,000~2,700자, 신년 2,500~3,200자, 주제 1,100~1,500자 |
| PDF | 웹 축소 목표 제외. 기존 웹 기반 심화 집필과 전체 분량 한도 유지 |

비율은 집필 목표이며 생성된 문자열을 임의로 자르는 비율이 아닙니다. 모델 특성에 따라 실제 글자 수에는 편차가 있습니다. 목표보다 길다는 이유로 재작성을 반복하거나 문장을 중간에 잘라내는 처리도 추가하지 않았습니다.

## 구조 변경

인생총운: 중복되는 도입/성향 세 장을 한 장으로, 대운별 설명은 하나의 흐름 장으로, 세 차례 마무리는 활용법 한 장으로 합쳤습니다. 원국 사주판, 여섯 영역, 미래 10년과 요청된 대운은 유지합니다. 총 11장입니다. 대운 통합 장에서 요청된 기간을 생략하면 기존 근거 검사와 함께 검출합니다.

신년운세: 도입/총운/전년 비교를 연결해 한 장으로, 상하반기/주의 시기/전략/질문/마무리를 한 장으로 정리했습니다. 여섯 영역과 **12개 절기 월운은 각각 유지**합니다. 월운 간지·절입 기간을 표시하는 기존 UI도 유지합니다. 총 20장입니다.

주제별 사주·궁합·이름: 상품별 질문과 기간별 설명의 구성은 유지하며 장별 목표와 상품 전체 목표를 함께 낮췄습니다. 자미두수도 장별 목표를 낮춥니다. 타로·점성술은 이미 짧아 소폭 조정했습니다. 무료 계산형 풀이에는 AI 호출이나 별도 축소 처리를 추가하지 않았습니다.

## PDF와 검증

PDF는 같은 웹 이야기의 심층판을 이어 쓰므로 통합된 장의 구성은 공유하지만, 웹 글자 수 지시와 웹 간결판 정책은 PDF 집필에서 제거합니다. 웹 원문·계획을 바탕으로 이유와 조건을 더 깊게 설명하는 기존 절차를 유지합니다. 기존 문장 예산 45,000자(리포트 전체 최대 60,000자)와 장별 상한, 결제 후 생성/캐시/24시간·동일 기기 정책도 바꾸지 않았습니다.

`tools/web-length-regression.js`에서 14개 상품 × 3개 연령의 구조, 12개월/미래 10년/배정 대운 유지, 대운 누락 차단, 서버 분량 정책 전달, PDF에 웹 축소 지시가 들어가지 않는 것을 검사합니다. 기존 생성/복구/결제/무료/PDF 회귀 검사도 수행합니다. 이번 최종 설정으로 실제 모델을 다시 호출해 전후 속도나 실제 글자 수를 측정한 것은 아닙니다. 이전 비교 샘플 측정값은 새 운영 설정의 측정값으로 재사용하지 않습니다.

최종 확인: `npm test` 33개 검증 명령이 종료 코드 0으로 통과했습니다. 실제 모델/결제는 모의 응답을 사용하는 회귀 검사이며, 이번 분량 설정의 실제 생성 시간은 미측정입니다.
