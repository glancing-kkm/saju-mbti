# 생성 지연 진단과 실행 구조 개선 — 2026-11-02

## 실제 운영 기록에서 확인한 점

현재 브라우저의 개인정보 없는 `ai-report-diagnostics-v2` 기록을 읽었다. 최근 인생총운에서 설계 응답 17,399ms, 본문 묶음 응답 38,880~90,395ms가 있었으며 90,395ms 요청은 503 이후 재시도했다. 다른 기록에는 4장 중 일부의 분량 검사와 표현 검사로 재집필한 흔적도 있다. 가장 최근 저장된 완성 보고서는 21개 장이다.

이 기록은 특정 입력/시점의 관찰이다. 서비스 전체의 평균이나 새로운 코드의 속도를 뜻하지 않는다. 이번 확인에서는 사용자 보고서를 다시 생성하거나 결제 토큰/본문을 출력하지 않았다.

## 코드 변경

- 웹 집필을 요청당 4장/동시 4개에서 요청당 2장/동시 최대 6개로 조정했다. 본문 분량과 전체 완료 후 한 번에 보여주는 방식은 유지한다.
- `compact-v1` 실행 프로필의 AI 설계 응답에서 내부용 `focus`, `connection`의 중복 생성을 제거했다. 독자에게 보이는 장 제목·결론·전체 프로필과 근거 있는 장간 연결은 AI가 작성한다. 내부 질문은 기존 상품 목차를 참조하고 연결 설명은 AI가 작성한 실제 links를 사용한다.
- 상담 주제/질문이 제목에 포함됐다는 이유로 설계 전체를 다시 쓰던 `themeIssues` 오검사를 수정했다. 직업을 제목의 주제로 삼지 않는 기존 검사만 유지한다.
- 실행 설정을 의미적 캐시 지문에서 제외했다. 기존 완성/부분 저장본의 내용과 조건이 같으면 실행 최적화 때문에 재결제/재집필하지 않는다.
- 세대 시작/완료의 전체 경과시간, 배치 크기, 누락 장 수와 거절된 응답의 문단 수/글자 수를 진단 로그에 추가한다. 본문·이름·생년월일·토큰은 로그에 남기지 않는다.
- PDF의 묶음 크기와 동시성, 본문 분량, 모델과 reasoning 설정, 실제 계산·근거 검증·결제 한도는 그대로 유지했다.
- 이전 브라우저는 원래 설계 JSON 계약을 유지하고 새 브라우저만 축약 계약을 사용한다.

## 검증

- `node tools/compact-report-regression.js`: 축약/이전 JSON 계약, 실제 근거 검사, AI 결론 보존, 내부 메타데이터 복원, 기존 의미적 캐시 재사용, 정상 상담 주제 오거절 방지, 14개 상품에서 기본 생성과 1회 재시도가 기존 40회 요청 범위에 들어가는지 검사. 통과.
- `node tools/ai-report-recovery-regression.js`: 최대 6개 요청만 진행, 중복 생성 억제, 결제 오류 무재시도, 기한, 사실 검증, 전체 완료 전 노출 차단. 통과.
- `node tools/reading-stage-regression.js`: 분석 사주판·전체 완료 전환·홈 이동/재방문·시간 미상·오류 상태 유지. 통과.
- `node tools/ai-full-report-regression.js`: 유료 14종/PDF 14종의 전체 집필·캐시·근거·복구 경로 통과.
- `AI_REPORT_FULL=1 node tools/free-ai-regression.js`: 무료/미리보기 23개 흐름의 AI 요청 0건 확인.

모든 새 코드의 모델 응답은 모의 응답으로 검사했다. 실제 모델을 통한 새 코드의 생성 속도·상담 품질·요청 제한 발생률은 아직 측정하지 않았다. 10초를 달성했다고 선언하지 않는다.

## 10초 목표와 사용자 선택

사용자가 웹 분량 유지를 선택했다. 웹 목표 분량은 줄이지 않았으며, 인생총운 21장 실측은 98.040초였다. 이전 요청 기록 약 175.496초 대비 이번 한 차례는 약 44% 짧았지만, 통제된 반복 비교가 아니므로 보장값은 아니다. PDF는 별도 심층판으로 결제 후 생성한다. 상세 실측과 기기·24시간 제한은 report-access-timing-2026-11-02.md에 기록했다. 저지연 유료 티어 구매나 모델 교체도 하지 않았다.
