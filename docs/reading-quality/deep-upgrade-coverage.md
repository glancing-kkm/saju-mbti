# 전체 풀이 심화 개편 — 적용 범위와 검증

2026-10-30. `deep-upgrade-handoff.md`의 구현 결과다. 기존 미커밋 작업(인생총운 편집 시안, 직업 필수 순차 입력, PDF 단락 추출, 워커 편집 자료)은 그대로 두고 그 위에 적용했다. 배포·푸시는 하지 않았다.

## 독자 경험의 공통 흐름

알아볼 수 있는 장면과 안에서 당기는 두 기준 → 강점이 부담으로 바뀌는 조건 → 지금 달라지는 점 → 선택지별로 얻는 것과 잃는 것, 판단 기준. 웹은 3~4문단, PDF는 소제목마다 확장한다. 계산 근거는 본문에서 빼서 접힌 "사주 근거 보기"로 옮겼다. 근거는 시스템마다 다르다.

| 시스템 | 실제로 잇는 계산 | 쓰지 않는 것 |
|---|---|---|
| 사주 | 주된·보조 성향의 실제 자리와 글자, 해당 연·월 간지, 현재 대운, 해마다·달마다 점수, 일지, 가장 옅은 오행 | 계산하지 않은 구조, 시주 미상일 때 시주 근거 |
| 타로 | 질문 주제 + 실제 카드 + 자리 역할(본인·상대·장애·조언·결과 등 10종) + 슈트·숫자 단계·방향, 슈트 분포·뒤집힌 카드 수 | 상대 속마음·사건·날짜 확인, 뽑지 않은 카드 |
| 점성술 | 주제별로 서로 다른 요구를 가진 두 행성, 두 행성 사이 실제 각도(없으면 없다고), 긴장 각도, 시간을 알 때만 하우스, 현재 트랜짓-출생 행성 각도, 신년은 선택 연도 월별 목성·토성 각도 | 같은 원소라는 이유의 각도, 시간 미상의 ASC·하우스 |
| 자미두수 | 명궁·천이궁(마주 보는 방) 주성, 신궁, 생년 천간 사화의 실제 위치, 현재·다음 대한 | 유년·삼방사정(계산하지 않았다고 명시), 위치를 정하지 않은 보조성 |
| 이름 | 글자별 소리 오행, 한자·획수, 원·형·이·정 수리, 계산된 후보 | 일반 사주 성격으로 대체 |
| 궁합 | 두 일간·일지·연지 관계, 4개 궁합 지표, 성향 막대 차이, 두 사람의 현재·다음 대운, 합친 해마다 점수 | 한 사람의 일반 성격으로 대체 |

## 적용 목록

### 유료·미리보기 (웹)
- 사주 공통 설명 `buildReadingNarrative`: 결론/근거/전개/행동 → 장면/부담 조건/지금 변화/선택 기준. 근거 문단은 `evidenceNote`로 분리해 접힘. 인생총운(건강), 신년운세(재물·일), 주제별 9종 첫 카드, PDF 대체 본문이 함께 바뀐다. 아동·학생·은퇴기·기혼 분기 유지.
- 인생총운 성향·직업·재물 편집 시안(기존 작업)은 그대로 유지.
- 자미두수: 1장 첫머리에 명반 해석(명궁·천이궁·사화·대한·선택 기준) 추가. "자미두수는 이렇게 읽어요" 이론은 접힘으로 이동. 웹에는 한자 궁 이름·"대한"을 쓰지 않는다.
- 타로: 계산형 8섹션을 새 구조로 교체(장면/반복되는 이유/카드별/흐름 변화/조건부 답/선택지 득실/조심할 해석/다음 확인 신호). 모든 카드에 같던 사전 조언·경고 문장 제거. 미리보기는 기존처럼 앞 2섹션만 공개.
- 점성술: `astroInsight`로 주제별 두 행성·각도·트랜짓 연결, 6섹션 계산형 전체 목차(신년 상·하반기, 궁합 시냅스트리 포함).

### 결제 후 AI 종합
- 타로·점성술: 앞 섹션을 고정하던 `mdMerge(keep…)`를 없앴다. 계산형 전체를 먼저 보여 주고, AI 응답이 검증(`tarotAIQuality`, `astroAIQuality`)을 통과하면 첫 섹션까지 전체를 대체한다. 실패하면 계산형 전체 유지(점성술은 기존 3섹션 축약 대신 6섹션 유지).
- 사주 계열 `hydrateDeepReading`: 장 5개씩 최대 3묶음, 동시 2개. 채택된 묶음만 캐시하고 다시 요청하지 않는다. 장마다 `focus`(이 장이 답할 질문)를 보낸다.
- 시스템별 근거 ID: 자미두수 `zw.*`, 궁합 `pair.*`, 이름 `name.*`. 해당 체계 장에 사주 ID만 넣거나, 실제와 다른 별·궁 주장, 계산하지 않은 유년 단정은 채택하지 않는다.
- 워커: `systemEvidenceText`(허용 ID 모양·라벨 길이 제한), 장 `focus`·PDF 소제목 `draft` 정제, 타로 프롬프트 8단계·자리 역할·슈트, 점성술 프롬프트에 정제한 트랜짓 각도·주제 행성·편집 원칙. 결제 확인·주문당 한도·모델·토큰 상한은 바꾸지 않았다.
- 클라이언트 AI 캐시 키 `v10-editorial` → `v11-depth`. 결제 토큰·히스토리는 지우지 않는다.

### 월별·지정일 운세 종료 (2026-10-30 추가 요청)
- 상품을 운영하지 않기로 해 입력 칸·렌더러(`renderMonthlyFortune`·`renderDaypickFortune`·V4 빌더·레거시)·가격·결제 분기·상담 항목·카탈로그·채팅 문구를 삭제했다. 신년·주제별·인생총운이 쓰는 달 점수 `_monthScore`와 이름 풀이 상수는 남겼다.
- 결제 워커 2종에서도 두 상품의 가격과 월 단위 금액 검증을 지웠다. 결과 카드 순서가 위치 번호를 쓰므로 빈 `p2`·`p3` 칸만 남겼다.

### 궁합·이름 (2026-10-30 추가 요청)
- 궁합: 1장 "두 사람이 반복해서 만나는 장면" — 가장 큰 성향 막대 차이, 일지 관계, 각자의 현재 대운과 합친 해마다 점수 최고 해, 그대로 둘지 맞출지의 득실과 기준. 성향 막대 값은 `personaAxesValues()`로 화면·PDF가 같은 계산을 쓴다.
- 이름풀이: 1장 머리에 이름 해석 — 첫소리 오행과 인상, 사주와 어긋나는 지점(용신 부재·누르는 기운·지금 나이에 걸리는 수리 자리), 합친 균형과 좋은 수리 수, 그대로 쓸지 바꿀지의 득실. "점수는 이렇게 나왔어요" 설명은 근거 상자로 접음.

### 무료
- 일일운세: "한 줄로 정리하면" 카드의 일반 활동 문단을 오늘 일진 천간이 평소 성향과 만나는 조건과 선택 기준으로 교체.
- 만세력: 계산표 아래 "이 명식을 생활로 옮기면"(장면·부담·지금·기준) 카드 추가, 근거는 접힘.
- 오늘의 점성술: 가장 강한 실제 트랜짓 각도의 성격으로 오늘 고를 일의 득실과 기준을 마지막에 추가.
- 즉문즉답: 답변 순서(결론 → 반복되는 이유 → 지금 달라지는 점 → 선택지와 기준)를 채팅 프롬프트에 추가.
- 오늘의 타로: 카드 id 해시로 고르던 관계·돈·일 문장 풀 제거. 메이저 22장은 카드별 과해지는 조건과 오늘 확인할 일, 마이너는 슈트×숫자 단계로 장면·과해지는 조건·확인할 일을 만든다(4섹션).
- 베딕: 달 별자리 × 현재 큰·작은 다샤를 한 장면과 기준으로 잇는 카드 추가.
- 마하보테: 요일 행성의 장점이 과해지는 조건과 선택 기준 추가.
- 무료 출생차트: "차트에서 먼저 읽을 장면"(실제 두 행성·각도·긴장 각도) 추가. 시간 미상은 하우스 미사용.

### 기존 PDF 14종
- 소제목 대체 본문 `rpFallbackParas`: 소제목의 질문(장면·부담·시기·선택·실천·근거)을 고르고, 보고서 안에서 아직 쓰지 않은 실제 근거 칸을 배정한다. 같은 문장은 보고서 전체에서 한 번만(`rpLedger`). 자미두수·이름·궁합은 각 체계 계산만 쓴다. 자미두수 "대상 유년의 변화"는 미계산을 밝히고 현재 대한·화기 궁만 점검 목록으로 준다.
- AI 채택 기준 `rpSectionQuality`: 일반론 비율, 계산 근거 인용, 소제목 관련성, 입력에 없는 연도, 기혼 새 연인, 앞 소제목과의 문장 반복, 자미두수 별·궁 대조·유년 단정.
- 소제목마다 `focus`와 계산 `draft`를 모델에 전달. 동시 요청 2개, 성공 묶음 캐시 재사용.
- 전체 글자 수: 부록 최소 3천 자 보장을 없애고, 본문이 크면 부록부터 줄인다. 그래도 넘치면 긴 소제목의 마지막 문단 → 긴 문단의 끝 문장 순으로 덜어 다시 배치한다(소제목 2문단·문단 2문장 유지). 상한 58,000자(요청 6만 자 이하).
- 기본 정보 쪽에 "해석에 쓴 계산"과 "소제목 본문 작성: N개 중 AI 종합 M개 · 계산 근거로 쓴 해석 K개"를 표시.
- `RP_VERSION` `v9-depth`. 이름 계산은 `nameModel()`로 분리해 웹과 PDF가 같은 계산을 쓴다(화면 출력 동일 확인).

## 한계

- 모든 AI 응답은 모의 데이터로 검사했다. 실제 모델 출력의 문체·논리·비용·대기 시간은 측정하지 않았다. 검증 규칙은 문장·근거 ID 검사이며 해석의 정확도나 미래 예측의 적중을 보장하지 않는다.
- AI가 없을 때 PDF 대체 본문은 소제목당 2~3문단으로, AI 종합보다 짧다. 근거가 부족한 소제목은 같은 장의 화면 풀이 문장으로 보탠다.
- PDF AI 요청은 묶음마다 최대 2회 재시도한다(기존 동작). 성공 응답마다 주문당 글 요청 한도(40회)에 포함된다.
- 자미두수 유년·삼방사정, 보조성 배치는 구현하지 않았다. 점성술 시냅스트리는 기존 계산(개인 행성 사이 각도)만 쓴다.
- 일일운세의 영역별(총운·재물·연애·건강) 문장과 시간대 카드, 신년운세의 월별 표 문장은 기존 계산 문장을 유지했다.
- 배포하지 않았다. 워커(`worker/saju-chat-worker.js`) 변경은 배포해야 실제 AI 프롬프트에 반영된다.
