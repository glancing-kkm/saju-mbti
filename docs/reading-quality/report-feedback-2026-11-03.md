# 반복 안내·그래프 불일치·연도별 본문 누락 수정

## 확인한 원인

- 본성 장 질문과 Worker 공통 문체 지침 모두 '복잡한 용어를 현실적인 언어로 바꿔보겠습니다'를 예시로 권장했다.
- 인생 그래프의 레이더는 향후 10년 평균, 아래 막대는 현재 연도 점수였다. 시간 범위가 달라 숫자가 달랐으며 두 그래프의 영역 수도 달랐다.
- 미래 10년 장의 집필 질문이 중요한 해 5~7개만 고르도록 지시했다. 표에는 10년이 있어도 개별 연도의 본문이 없어도 검증을 통과했다.

## 변경

- 문체 지침은 설명 뒤 구체 장면으로 바로 연결하도록 수정했다. 저장된 원고에 남아 있는 동일 안내 문장도 웹/PDF 공통 readerText에서 지운다. 다른 문장을 생성하거나 추가하지 않는다.
- lcYearAreaScores의 동일한 현재 연도 7개 영역 데이터를 레이더와 막대에 전달한다. 제목에 동일 연도를 표시한다. 0점도 유효한 값으로 보존한다. 점수 계산식은 변경하지 않았다.
- 미래 장은 배정된 10개 연도를 모두 순서대로, 해마다 별도 소제목과 설명으로 집필한다. 간지는 예시로 고정하지 않고 해당 연도 ledger를 사용한다.
- chapterIssues는 각 연도의 근거 참조, 유일한 소제목, 35자 이상의 실제 설명, 시간순 배치를 검사한다. 표에 연도가 존재하는 것은 본문 충족으로 보지 않는다. 웹과 PDF의 공통 저작 검증을 적용한다.
- 합성 모의 모델 fixture를 새 계약에 맞췄다. 실제 계산 결과나 상품·가격·결제 로직은 변경하지 않았다.

## 검증

- report-feedback-regression: 실제 계산형 인생총운 HTML에서 레이더/막대의 영역·값이 완전히 같은지 확인. 2027/2032/2033 본문 삭제, 제목만 남기기, 연도 근거 삭제를 각각 거절. 안내 문장의 웹/PDF 렌더 제거 확인. 통과.
- ai-full-report-regression: 14 유료 + 14 PDF 집필 파이프라인, 누락 재시도, 캐시, 원자적 결과 노출. 통과.
- compact-report-regression: 기존/축약 계약, 캐시, 제한된 동시 요청, 결제 요청 범위. 통과.

- `npm test`: 전체 회귀 테스트 통과(유료 14종/PDF 14종, 무료 AI 호출 차단, 결제·접근 제한·복구 포함).

검증용 모델 응답은 합성 데이터다. 실제 AI 원고를 새로 생성하거나 과거 사용자의 저장된 결과를 원격 변경하지 않았다. 운영 배포는 이번 요청에서 수행하지 않았다.


## 추가 피드백: 반복 대조·직업 소개와 끝 부록

- 공통 Worker 지침의 ‘하지만 이 장점에는 반대쪽 모습도 있습니다’ 권장 예시를 제거했다. 같은 전환어를 매 장 강제하지 않는다.
- 직업을 매번 입력정보라고 소개하라는 지침을, 해당 일의 구체 장면과 조건으로 바로 설명하는 지침으로 바꿨다. 직업을 사주로 알아낸 사실처럼 서술하지 않는 규칙은 유지한다.
- readerText에서 저장된 원고의 위 반복 대조 문장을 ‘하지만’으로 줄이고, ‘사무직이라는 현재 정보를 토대로 연결해 보면’ 형태의 메타 도입절을 제거한다. 실제 직업별 조건이나 행동 설명은 유지한다.
- 웹/PDF 공통 마지막 ‘해석 근거와 한계’(신년의 ‘명리학적 해석 근거’ 부록 포함)를 생성하는 함수와 호출, 웹 목차 링크를 제거했다. 원국·계산 데이터, 본문 근거, 기본 출생정보와 시간 미상 안내는 유지한다.
- report-feedback-regression에서 14종 웹/PDF의 부록 및 링크 부재와 기존 원고 정리, 의미 있는 직업 조건 보존을 확인했다. ai-full-report-regression도 통과했다. 실제 유료 모델 재호출 및 운영 배포는 하지 않았다.
