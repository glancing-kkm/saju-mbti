# 주제별 사주 심층상담 적용 — 2026-11-02

## 적용 범위

11개 기존 상품(궁합, 연애, 결혼, 재회, 재물, 직업·사업, 학업·시험, 우리 아이, 자녀·임신, 건강·생활, 이름풀이·작명)의 추가 질문과 유료 웹/PDF 집필 계약을 분리했다. 사용자 예시의 명식·직업·사건·절입 시각은 상품 설정에 넣지 않았다.

기존 계산 엔진, 상품 ID·가격, 결제·서명·이용 한도와 무료 계산형 원칙을 유지한다. 기존 작업 폴더에 있던 AI 본문/PDF 렌더링 수정도 보존했다.

## 파일과 역할

- `assets/premium-saju.js`: 11개 상품의 선택 질문, 조건부 세부 질문, 독립적인 목차, 서사 기법, 분량 목표, 주제별 제한. 계산·사용자 예시 데이터 없음.
- `index.html`: 기존 단계별 입력기에 선택형 질문을 연결. 직업 필수 유지. 추가 질문은 건너뛰기·기타·답변하지 않음 지원. 연애 상태에 따른 관계 기간 조건부 노출. 같은 출생정보/주제의 답변·질문 복원 및 다른 출생정보 격리. 기존 자유 질문 초안도 새 질문 칸으로 복원. 새 자산 버전 갱신.
- `assets/ai-report.js`: 상품별 질문 프롤로그→원국→주제별 강점·갈등→운→현실 선택→질문 회수. 현재 계산 엔진으로 절기 기준 12개 명리월 자료를 주제별 상담에도 제공. 3~5년 주제에서는 해당 범위 세운 배정. 실제 월 근거를 계획과 집필 응답에 보존. 한자 모름 선택 시 한자·수리 근거를 AI 입력에서 제외. 상대 시간 미상 한계 명시. PDF 장별 본문 예산 제한.
- `worker/saju-chat-worker.js`: 상품별 편집 계약·충분한 장 질문·추가 답변 전달. 명리 계산, 해석, 사용자 진술, 조언과 미확인 영역을 구분하는 집필 규칙. 재회 거절/폭력, 아동, 임신·건강, 이름 후보 관련 범위 제한. provider API나 결제 로직 변경 없음.
- `assets/report-pdf.js`: 작업 폴더의 웹 기반 PDF 구성 유지. 새 주제별 상품은 같은 목차로 별도의 PDF 심화 집필을 요청. 기존 출력 메타데이터(`ai-full-v1`, AI/계산형 coverage) 호환성 복구.
- `tools/premium-saju-regression.js`, `tools/premium-saju-browser.js`: 새 계약과 입력 흐름 검증. 기존 런타임에도 새 설정 모듈 연결. `package.json`의 테스트에 회귀 검사 추가.

## 입력 예

| 상품 | 추가로 받는 내용 |
| --- | --- |
| 궁합 | 관계 단계, 주요 고민, 교제 기간, 갈등, 함께 결정할 시점 |
| 연애 | 연애 상태, 관심 주제, 관계가 있을 때 기간, 어려움과 바라는 관계 |
| 결혼 | 혼인/재혼 단계, 관심 주제, 기간, 계획 시점, 생활 조건 |
| 재회 | 이별 상태·기간·원인, 연락/거절 상태, 교제 기간, 달라진 조건 |
| 재물 | 경제활동, 관심 주제, 수입 방식·안정성, 상환 부담, 목표·계약 시점 |
| 직업·사업 | 직업 상태, 고민, 직무·경력, 선택지, 업무 만족도, 결정 시점 |
| 학업·시험 | 시험 목적, 준비 단계, 분야·일정, 어려움, 공유할 성적·취약 과목 |
| 우리 아이 | 교육 단계, 관심 주제, 활동, 실제 관찰, 최근 환경 변화 |
| 자녀·임신 | 가족계획 단계, 관심 주제, 고민, 돌봄 여건 |
| 건강·생활 | 근무 형태, 개선 목표, 생활 리듬, 수면·운동 습관 |
| 이름 | 상담 목적, 실제 한자 확인 여부, 느낌·의미, 선호/제외 조건, 입력 후보 |

각 상품 마지막에는 자유 질문을 받는다. 진단·생식 정보나 정확한 재산 금액은 요구하지 않는다. 상대방 출생정보는 기존 궁합 입력을 사용한다.

- `npm test`: 기존 전체 회귀 검사 통과. 무료/미리보기 23개 흐름에서 AI·인물 생성·번역 추론 요청 0건.
- `node tools/premium-saju-regression.js`: 11개 서로 다른 목차/집필 계약, 조건부 단계, 미입력 허용, 긴 질문 보존, 사용자 격리, 동일 계산 결과의 일관성, 개인 사건의 계산 근거 오염 방지, 다른 명식의 근거 차이, 상대 정보 없음 차단, 상대/본인 시간 미상과 한자 모름 처리, 서버 계약 전달 통과.
- `node tools/ai-full-report-regression.js`: 14개 유료·14개 PDF 집필 경로, 근거 검증·부분 복구·캐시·표시 검사 통과. 최종 변경 후 재실행 통과.
- `node tools/ai-report-recovery-regression.js`: 최종 변경 후 재실행 통과. 중복 요청 억제, 부분 표시, 지불 오류 무재시도, 제한 시간 및 허위 근거 차단 유지.
- 실제 Chrome, 모의 AI 응답: 모바일/데스크톱 웹 28개 화면, PDF 14종/227쪽, 실행 오류·가로 넘침·PDF 본문 넘침 없음. `/tmp/premium-topic-review`.
- 실제 Chrome 입력 22개 화면: 오류/가로 넘침 없음, AI 요청 0건. `/tmp/premium-topic-intake-review`.
- `wrangler deploy --dry-run`: 빌드 통과. 배포·설정·비밀키 변경 없음.

모델 응답은 모의 데이터로 검사했다. 실제 유료 AI의 문장 품질·개인화 체감·권장 글자 수 달성·생성 시간은 이번 검증에서 측정하지 않았다. 테스트 문구는 개발 산출물에만 존재하며 실제 사용자 결과로 저장하거나 혼합하지 않았다.

## 범위와 남은 제한

- 목차는 사용자 예시의 각 장을 그대로 늘리는 대신 중복 주제를 묶어 구성했다. 웹 목표 3,000~10,000자는 상품별 가이드이며 고정 할당량이 아니다. PDF는 근거와 생활 조건을 더 자세히 쓰도록 설정하고 전체 6만자 이내 지침 및 장별 본문 상한을 둔다.
- 신규 작명은 기존 상품 안에서 방향과 입력 후보를 비교한다. 새 이름 후보 생성 엔진이나 공식 인명용 한자 등록 가능성 확인 기능을 추가한 것은 아니다.
- 출생 지역·시간 입력/보정은 기존 엔진 그대로다. 전 세계 도시·역사적 시간대/서머타임 추가 검증이나 별도의 출생시각 구간 계산기는 이번 변경에 포함하지 않았다.
- 추가 상대/부모 명식을 새로 받는 기능은 만들지 않았다. 실제 두 원국 계산은 기존 궁합 상품에서만 한다. 다른 주제에서는 제공되지 않은 배우자·부모의 성향을 생성하지 않는다.
- 선택 질문 미입력으로 생성은 중단하지 않는다. 재회 상황 등 정보가 부족한 경우 실제 원인/상대방 분석은 제한하고 본인의 원국과 준비 조건을 다룬다.
- 정식 신강약·격국·조후·용신 판정 엔진은 추가하지 않았다. 계산되어 있지 않은 학파별 판정은 집필 금지 규칙 유지.
- 운영 배포는 하지 않았다. 반영 시 새 설정 자산과 브라우저 코드, Worker, PDF 코드를 함께 배포해야 한다.
