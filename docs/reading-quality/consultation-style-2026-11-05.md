# 상담형 집필 방식 고도화

## 적용 범위

- 유료 사주 14개 상품(총운·신년·주제·궁합·이름·자미두수)의 설계와 본문, 웹과 PDF에 공통 상담형 정책을 적용한다.
- 타로·점성술의 전용 생성 경로에는 해당 체계와 주제에 맞는 초점을 적용한다. 실제 카드·자리·방향, 행성·각도, 궁·별, 이름 자료를 재계산하지 않는다.
- 무료·미리보기는 계산형으로 유지하며 AI 호출을 추가하지 않는다. 이번 변경은 무료 문구 전체를 새로 쓴 작업이 아니다.

## 집필 방식

핵심 해석 → 실제 근거의 상호작용과 이유 → 생활에서 나타나는 모습 → 달라지는 조건과 선택 기준으로 이어진다. 원국 안내 장의 사실 설명 역할은 유지한다. 질문·반대 조건·훈계로 모든 장을 같은 형태로 만들지 않는다. 같은 근거를 다시 언급할 때는 앞 장을 복사하지 않고 다음 영역에서 달라지는 뜻을 설명한다.

사주는 원국과 운, 타로는 카드 간 관계와 질문, 점성술은 실제 배치가 나타내는 욕구의 차이, 자미두수는 궁과 관련 궁·대한, 이름은 실제 글자와 사용 목적을 중심으로 쓴다. 주제별 재물·관계·가족·건강 등의 초점을 분리한다.

서로 다른 장에서 같은 조건의 같은 선택을 권유/금지하지 않도록 기존 계획을 대조하는 지시를 추가한다. 수입 활동 확대와 자금 투입 확대처럼 다른 판단이라면 조건을 설명한다. 이는 의미상의 모든 모순을 자동 증명하는 검증기가 아니라 집필 원칙이다.

다른 서비스 원문은 코드·프롬프트에 복사하지 않았다. 성씨별 인물 판단, 질병 호전·임신·수익 확정 등을 도입하지 않는다. 직업을 계산 근거로 역추론하지 않는 앞선 제한도 유지한다.

## 상세도와 비용

- 주제별 웹 집필 목표를 기존 상품 분량 범위의 상단으로 배분한다. 분량보다 이유·조건·사례에 집중한다.
- 타로 목표: 3장 1,100~1,600자, 5장 1,600~2,200자, 10장 2,200~3,200자. 호출 횟수와 출력 토큰 예산은 바꾸지 않는다.
- PDF는 웹의 핵심 해석을 유지하고 이유와 적용 차이를 심화한다. 기존 장별 한도 및 전체 6만자 제한을 유지한다.
- 생성 요청의 횟수·병렬 처리·재시도·결제 및 접근 정책, 모델 선택을 변경하지 않는다. 더 상세한 실제 출력은 토큰 사용량이나 응답 시간에 영향을 줄 수 있으며 속도 개선을 보장하지 않는다.

## 검증

- consultation-style-regression: 14개 상품 × 설계/본문 × 웹/PDF, 서버의 질문 길이 한도, 분야별 정책, 근거·불확실성 유지, 타로와 점성술 전용 경로를 검사한다.
- 실제 API: 가상 테스트 출생정보로 계산한 원국에서 재물 장 하나를 설계·생성했다. gpt-5.6-luna, 약 1,030자, 기존 planQuality/chapterIssues 검사 통과. 첫 문단의 핵심 해석과 이어지는 근거·생활 조건을 확인했다. API 두 단계 합계 약 20.8초였으며 전체 리포트 소요 시간은 아니다.
- 실제 샘플의 입력 토큰 13,233개, 출력 토큰 1,272개(추론 포함). 사용자 주문·결제·KV를 읽거나 쓰지 않는 임시 원격 프리뷰에서 수행했다. 테스트 출생정보와 완성 원고는 /tmp에만 저장했다.
- 모든 상품의 실제 AI 완성 원고를 생성하거나 점술적 정확성을 입증한 것은 아니다. 전체 상품은 모의 모델을 이용한 기존 통합 검사로 회귀를 확인한다.
