# 전체 완료 후 결과 전환 — 2026-11-02

## 사용자 요구

순차적인 장별 노출을 중단한다. 전체 풀이가 준비되지 않은 결과 화면에서 `풀이 중입니다`를 보여주지 않는다. 입력한 출생정보로 계산한 실제 사주판과 분석 모션을 별도 화면에 표시하고 모든 본문이 검증되면 결과 화면으로 한 번에 전환한다.

## 적용

- `assets/reading-stage.js`: 별도 `view-analysis` 생성·수명 관리. 실제 `_saju`의 천간·지지와 오행을 4열 사주판으로 표시. 시간 미상은 시주를 생성하지 않고 미상 표시. 입력/보정 시각 참고 문구 재사용. CSS 궤도·빛 스캔·호흡 모션. 가짜 백분율·카운트다운·자동 건너뛰기 없음. 동작 감소 설정에서는 모션 제거.
- `index.html`: `gotoCard`, 결제 후 재렌더, `showView('result')`에서 미완성 유료 본문이면 분석 화면을 먼저 연다. 기존 2~4초 뒤 사라지는 `playReveal`이 이 분석 화면을 덮거나 중간에 끝내지 않게 한다. 홈/입력 등으로 이동하면 전환 권한 취소.
- `assets/ai-report.js`: 승인된 장은 내부 캐시에 저장하되 DOM에는 쓰지 않는다. 모든 장 검증 후 완성된 문서를 한 번만 렌더링한다. 같은 보고서 진행 중 재방문해도 최종 방문의 분석 화면을 정상 완료 처리한다. 이미 완성된 보고서는 추가 요청·인위적 지연 없이 표시한다. 실제 실패는 분석 화면에서 사실대로 안내하고 일부 본문을 결과처럼 노출하지 않는다.
- 생성 속도 개선: 장 집필 요청에서 해당 묶음의 계산 근거와 공통 원국을 유지하고 관련 없는 시기 자료·다른 장의 상세 집필 지시를 제외한다. 전체 장의 핵심 결론과 직접 연결된 장의 근거·연결 설명은 보존한다. 계산·모델·본문 목표 분량·동시 요청 수·결제 로직은 변경하지 않았다.

## 검증

- `npm test`: 전체 회귀 검사 통과. 이후 요청 자료 축소와 분석 화면 메시지 보정은 관련 AI 전체 집필·복구·전환 테스트 및 실제 Chrome으로 재확인했다.

- `tools/reading-stage-regression.js`: 미완성 결과/일부 승인 장 숨김, 실제 사주판, 클릭으로 건너뛰기 차단, 전체 완료 후 전환, 캐시 재사용, 홈 이동 후 늦은 응답 전환 차단, 생성 중 나갔다 돌아온 경우 전환, 시간 미상, 오류 상태, 필요한 근거·전체 목차 유지.
- `tools/ai-report-recovery-regression.js`: 기존 복구·한도·기한 검사를 유지하면서 부분 표시 기대를 전체 완료 기대에 맞춤. 실제 계산 오류 검증은 유지.
- `tools/ai-full-report-regression.js`: 유료 14종·PDF 14종의 생성/캐시/근거 검증 경로 통과. 작업 폴더의 사주판 도식 변경에 맞춰 표 또는 실제 사주판 존재를 확인한다.
- `tools/reading-stage-browser.js`: 실제 Chrome에서 390/1069px, 응답을 제어해 일부 요청만 끝난 구간과 최종 완료 구간을 확인. 결과 화면은 완료 전 숨김, 클릭해도 분석 화면 유지, 완료 후 대기 문구/미완성 장 없음, 가로 넘침/실행 오류 없음. 개발용 모의 응답만 사용. `/tmp/reading-stage-review`.
- 요청 자료 크기: 인생총운·신년·재물·연애의 검증용 19개 묶음을 Worker 정제 함수에 통과시킨 후 비교. 모델로 전달하는 정제 데이터의 문자 수가 37~65% 감소했다. 실제 생성 시간 단축률을 뜻하지 않는다. `/tmp/reading-stage-payload-stats.json`.

실제 유료 모델의 속도·실패율은 이번 검증에서 측정하지 않았다. 테스트 문구는 실제 사용자 결과에 섞지 않는다. 무료 계산형과 타로·점성술의 기존 대기 화면, 별도 PDF 파일 생성 화면은 이번 사주 결과 전환 변경의 대상이 아니다.

운영 배포 전 코드 변경이다. JS/CSS 자산 버전을 함께 갱신했다.
