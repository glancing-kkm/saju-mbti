# 추가 상담 질문 축소

- 인생총운·신년운세·자미두수는 필수 직업만 남기고 focus/goal/timing의 추가 단계를 제거했다.
- 11개 주제 상품은 선택 질문 2~3개로 축소했다. 재회는 이별 시점·연락 상태·이유와 자유 질문 4개를 남겼다.
- 유사한 목표·관심 주제·고민·기간 질문을 중복 수집하지 않는다. 상세 사연은 하나의 자유 질문에 적을 수 있고 미입력 시에도 진행한다.
- 이름 상담의 실제 한자 확인, 궁합의 상대 출생정보, 연도·출생지·시간 미상 지원은 유지했다. 계산·결제·본문 목차는 바꾸지 않았다.
- 직업 필수 정책과 같은 출생정보의 저장값 재사용을 유지한다. 삭제한 질문은 렌더링과 counselRead의 수집 대상에서 제외한다.
- 반복되던 일반적인 추가정보 안내 대신 현재 질문의 구체적인 이름을 안내한다.

검증: counsel-input-regression, premium-saju-regression에서 질문 개수, 필수 직업 유지, 질문 미입력·건너뛰기, 저장값 복원과 사용자 분리, 11상품 목차·근거·서버 전달을 확인했다. 운영 배포는 아직 하지 않았다.
