# 모든 풀이의 예상 진행률 및 작성 속도 개선 — 2026-11-03

## 적용 범위

사주 14개 AIReport 상품(인생총운·신년·주제별·자미두수·이름풀이 포함), 타로, 점성술, 공통 계산형 대기 화면, PDF 생성 화면에 ReportProgress를 연결했다. 무료 계산형 상품에는 AI 호출을 추가하지 않았다.

진행률은 모델이 작성한 토큰 비율이 아닌 **예상 진행률**이다. 실제 완료 작업과 경과 시간을 함께 반영한다. 이전 완료 시간은 상품별 숫자 통계만 브라우저에 보관한다. 대기 중 최대 98%, 검증 및 완료 처리 후에만 100%가 된다. 오류나 화면 이탈 시 타이머를 중단한다. 이미 계산이 끝난 무료 결과는 가짜 수초 대기를 없애고 즉시 완료로 표시한다.

## 속도 변경

- 앞선 compact 실행 방식 및 웹/PDF 생성 분리를 유지한다.
- OpenAI 유료 챕터 집필은 결론과 두 개 이상의 근거 참조가 있는 확정 계획을 전달받았을 때만 reasoning effort 기본값 low를 사용한다. 전체 재설계 대신 해당 장의 설명을 확장하도록 지시한다. 모델, 분량 상한, 근거·카드 검증은 유지한다.
- `OPENAI_REPORT_WRITING_EFFORT=medium`으로 집필 추론 설정을 되돌릴 수 있다. 계획이 없는 기존 경로에는 이 기본값 변경을 적용하지 않는다.
- 타로와 점성술은 입력·언어·현재 결제 토큰을 포함한 동일 요청을 공유하고, 검증을 통과한 응답만 메모리에 10분간 최대 16개 보관한다. 잘못된 응답은 재사용하지 않는다. 결과 채택 시 기존 검증을 다시 거친다.

## 검증

- smooth-progress-regression: 응답 없이도 점진 이동, 98% 상한, 명시적 완료, 역행 금지, 오류/이탈 정리, 검증된 응답만 재사용, 집필 정책과 rollback 통과.
- all-reading-progress-browser: 실제 Chrome에서 390/1069px, 16종 경로 × 2 화면 크기 총 32개 확인. 가로 넘침·페이지 오류 없음. 유료 AI 호출은 하지 않고 응답을 대기시킨 UI 검증이다.
- reading-system-depth-regression: 카드가 바뀌지 않는 동일 요청은 검증된 응답을 재사용하고, 다른 질문에 대한 잘못된 카드 응답은 거절하는 회귀 테스트를 포함한다.
- 전체 npm test의 마지막 테스트에서 기존 '동일 입력도 반드시 재호출한다' 가정을 새 캐시에 맞게 수정했다. 다른 테스트는 통과했으며 마지막 테스트를 별도로 재실행해 통과했다.

## 측정과 운영 상태

2026-11-02의 웹 약 98초, 최초 PDF 약 45.4초는 **이 변경 전**의 실제 단일 측정이다. 이번 low 집필 설정의 실제 모델 호출 시간과 장문 품질은 아직 재측정하지 않았다. 10초 완료를 보장하지 않는다. 새 브라우저 테스트의 지연은 모의 지연이며 실제 성능 수치로 사용하지 않는다.

2026-11-03 확인 시 운영 Pages에는 ReportProgress와 report-access가 배포되어 있지 않았다. 이 문서의 변경은 작업 트리에 있으며 GitHub 푸시/운영 배포 전이다. 이전 접근 제한 변경도 포함되어 있으므로 배포할 때는 채팅/결제 Worker를 먼저 반영한 뒤 Pages를 배포하고 기존 탭을 새로고침해야 한다.

PDF 파일의 실제 렌더링 레이아웃은 이번 변경으로 수정하지 않았다. PDF 진행률은 이전 접근 제한 및 생성 단계 검증에 추가된 공통 예상 애니메이션을 사용한다.
