# 전체 카테고리 적용 경로 점검 (2026-11-06)

인생총운만 변경한 상태가 아닙니다. 지난 변경의 공통 상담/분량 정책은 14개 정규 AI 상품, 유료 타로와 점성술에도 연결되어 있었습니다. 이번에는 보조/이전 형식의 누락 경로까지 점검해 보완했습니다. GitHub 푸시·운영 배포는 하지 않았습니다.

## 적용 경로

| 경로 | 적용 방식 |
|---|---|
| 사주 총운·신년·9개 주제·궁합·이름·자미두수 | 기존 실제 계산 자료 → 판단표 → 장별 새 내용 → 근거 연결 → 본문 검증 |
| 유료 타로 3/5/10장, 12개 주제 | 실제 카드/방향/자리와 조합을 주제별 독립 질문에 연결 |
| 유료 점성술 12개 주제 | 실제 행성/하우스/각도와 해당 주제의 질문을 연결 |
| 무료 계산형·미리보기 | 기존 계산/템플릿과 결정적 이야기 엔진 유지, AI 호출 추가 없음 |
| PDF 정규 경로 | 웹 이야기의 심층판, 웹 분량 축소 지시 제거 |
| 이전 PDF 템플릿 경로 | 동일한 심층판 준비 함수를 사용. 페이지의 장 ID가 달라 해당하지 않는 웹 문단/계획은 전달하지 않음 |
| 예전 reading-deep/report-* 등 보조 경로 | 메타데이터에서 실제 상품/체계를 정규화하여 같은 주제별 상담 정책 전달 |

## 이번 보완

- 예전 형식의 리포트에도 `consultationFocus`와 상품별 상담 질문을 전달합니다. 사주 근거를 타로·점성술·자미두수의 근거로 섞지 않습니다. 유료 생성 문체도 현재 합니다체로 통일합니다.
- 공유 이야기 엔진에 상품별 질문과 장별 새 정보 역할을 넣습니다. 이는 계산을 바꾸거나 AI 호출을 추가하는 작업이 아닙니다.
- 결혼·재회·건강·학업·아이·자녀계획 장을 모두 core/love로 묶지 않고 각각 구분합니다. 실제 배정 가능한 신호 안에서 계획을 구성합니다.
- 이름풀이/자미두수 등 기존 14개 상품과 두 PDF 진입점에 적용 여부를 확인합니다. PDF의 별도 장이 다른 ID의 웹 원고를 참조하지 않도록 합니다.
- 모든 변경된 브라우저 모듈에 새 자산 해시를 적용했습니다.

## 검증 범위

`all-category-consultation-regression.js`는 5개 체계 × 12개 주제 × 웹/PDF의 120개 **정책 조합**을 점검합니다. 실제 판매 SKU가 120개라는 뜻은 아닙니다. 공유 엔진의 4개 체계 × 12개 주제에서는 계산 자료 보존, 장 질문, 새 내용 역할과 서버 전달을 검사합니다.

기존 회귀 검사는 실제 지원되는 14개 유료/PDF 상품, 타로 36개 조합(12주제×3배열), 점성술 12주제와 무료/미리보기 23개 경로의 AI 미사용 등을 포함합니다. 테스트의 모델/결제 응답은 모의 데이터입니다. 이번 변경으로 모든 상품의 실제 AI 원고를 새로 생성해 전문가 검수를 완료했다고 주장하지 않습니다.

이번 작업은 빠진 경로를 연결하고 공통 생성 규칙을 통일하는 변경입니다. 기존에 저장된 완성본을 일괄 재집필하거나 사용자 데이터에 과거 사건을 추가하지 않습니다. 권장 웹 분량과 PDF 깊이 유지 정책은 [웹 분량 적용](web-length-policy.md)을 그대로 따릅니다.

최종 결과: `npm test` 34개 검증 명령이 종료 코드 0으로 통과했습니다. 이전 PDF 템플릿의 상품 종류 전달 보완 후에도 해당 템플릿/메일 회귀 검사를 별도로 통과했습니다.
