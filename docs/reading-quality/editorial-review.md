# 인생총운 성향·직업·재물 — 편집 검토

2026-10-30. 인생총운의 세 부분을 먼저 다시 작성하는 시안이다. 다른 카테고리의 본문과 명식 계산 공식은 바꾸지 않았다.

## 달라진 내용

- 성향: 좋은 특성 나열 대신 함께 나타나는 두 기준, 그 기준이 충돌하는 장면을 쓴다.
- 직업: 직업 이름 추천과 별개로, 능력이 쓰이는 업무 조건과 소모되는 조건을 구분한다.
- 재물: 수입을 만드는 방식, 준비·수정·책임 비용 때문에 실속이 사라지는 조건을 쓴다.
- 세 부분의 현재 운 설명과 선택 기준은 서로 다른 장면으로 풀었다.
- 두 성향이 모두 실제 계산에 존재할 때만 해당 조합의 문장을 선택한다. 단일 성향만 있는 명식은 억지로 모순을 만들지 않고 기존 설명을 유지한다.
- 구체적인 생애 사건을 정답으로 쓰지 않는다. 돈·직업의 미래 성과를 확정하지 않는다.

## 근거와 한계

이 변경은 새 명리 판정법이 아니라 계산된 원국과 현재 운을 서술하는 편집 규칙이다. 성향의 등장 수, 천간/지지 위치, 해당 대운을 이용하며, 월령·통근 등을 종합한 새 용신·강약 공식을 도입한 것은 아니다. 조합별 표현은 같은 계산 근거를 가진 여러 사람에게 공유된다. 특정인만의 정확한 성격이나 경험을 보장하는 결과가 아니다.

본문의 흥미와 납득 가능성은 실제 읽기 평가가 필요하다. 자동 검사는 근거의 존재·문단 구분·출처·전달 경로를 확인하며, 명리 전문가의 검토나 미래 예측 적중률을 대신하지 않는다.

## 검토할 자료

- `editorial-samples.md`: 제공된 명식과 비교용 두 명식, 세 부분씩 총 아홉 개 작성 시안.
- `node tools/build-editorial-review.js`: `/tmp/saju-editorial-review/index.html`에 기존 문장/새 문장 비교 화면 생성. `assets`는 현재 프로젝트를 참조한다.
- `node tools/reading-editorial-regression.js`: 120명식 × 3부분의 실제 근거 존재, 시각 미상, 개인 사건 미사용, AI의 부모/자식 중복 교체 방지, PDF 추출 확인.

## AI와 PDF

세 부분을 각기 다른 id로 AI에 전달한다. 선택한 근거, 강점이 부담으로 바뀌는 지점, 실제 운의 맥락, 선택 기준을 편집 자료로 보낸다. 입력 진술은 계산 근거와 분리한다. 기존 상위 섹션과 새 부분을 동시에 바꾸지 않는다. AI 응답은 기존 품질 검사에 더해 네 문단, 이 부분에 해당하는 두 성향의 참조 여부를 확인한 뒤 채택한다.

PDF는 같은 웹 원문에서 제목·본문·단락 역할을 추출한다. AI/PDF 캐시 버전은 변경했으며 이전 본문으로 덮어쓰지 않게 했다. 실제 모델 출력의 문체와 비용·대기 시간은 이번 모의 회귀 검사에서 측정하지 않았다.
