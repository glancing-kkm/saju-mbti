# 전 분야 공통 편집·스토리 설계 적용 — 2026-11-03

## 적용 범위와 분리 원칙

- 사주 인생총운·신년·궁합·주제별, 자미두수, 이름풀이: 기존 AIReport 유료 14종과 기존 PDF 14종에 공통 문구 편집·제목 처리·기간 누락 검사를 사용한다.
- 타로: 12주제 × 3/5/10장과 무료 일일 타로의 기존 카드 선택·의미 데이터는 유지한다. 실제 카드 근거와 스프레드의 이야기를 유지하고 공통 문구·제목·본문 줄바꿈을 연결한다.
- 점성술: 총운에 한정됐던 로컬 스토리 설계와 출생차트 검증을 12주제로 확대한다. 새로운 행성 위치나 시기 계산은 하지 않는다.
- 무료 사주·일일·만세력·MBTI·기타 계산형·무료 타로·무료 점성술은 계속 계산형이다. 공통 편집은 문자열/HTML 처리이며 AI·이미지·번역 네트워크 호출을 추가하지 않는다.
- 공통 진행률과 전체 완성 뒤 한 번에 노출하는 기존 흐름은 유지한다. 이번 변경으로 모델 호출 수를 늘리지 않는다.

현재 별도 PDF 상품이 있는 범위는 기존 14종이다. 타로·점성술의 새로운 PDF 상품이나 결제 항목을 신설한 것은 아니다.

## 변경 사항

1. ReadingVoice에 cleanText/markdown/headingHTML/periodIssues 공통 함수를 두고 AIReport, 타로·점성술의 일반/기록/한 페이지 렌더러가 사용한다. 반복되는 집필 안내·장점의 반대쪽 예고·직업 정보 소개절을 줄이되 의미 있는 실제 조건과 불확실성은 보존한다. script/style/code/pre/textarea와 HTML 속성은 편집 대상에서 제외한다.
2. '해석 근거와 한계', '명리학적 해석 근거'라는 정확한 제목의 중복 부록을 Markdown/DOM 출력에서 제외한다. 본문 근거와 출생시간 미상·미계산 범위 안내는 남긴다.
3. 제목의 짧은 끝말과 본문의 짧은 끝어미를 기존 규칙에 맞게 묶고, 단어를 보존해 줄바꿈한다. 타로·점성술 기록 화면의 본문도 16px 기준, 왼쪽 정렬, 일정한 단어 간격으로 맞춘다.
4. Worker의 공통 편집 원칙을 타로·점성술·사주·자미두수·이름풀이 집필 프롬프트에 연결한다. 유료 타로·점성술도 '당신', 합니다체를 사용하고 무료 문체는 유지한다.
5. 사주 주제별 미래 장에서도 배정된 모든 연도의 독립 설명을 확인한다. 월별 장은 12개 실제 명리월의 소제목과 본문이 있어야 한다. 원국과 운 계산은 변경하지 않았다.
6. 점성술 신년은 제공된 yearTransits의 각 월을 구분해 설명하도록 지시·검사한다. 기준일 행성 위치를 월 전체의 사건이나 정확한 변곡일로 취급하지 않는다. 월별 계산 데이터가 없으면 새 월운을 만들지 않는다.
7. 점성술의 12개 상품에 서로 다른 로컬 story plan을 전달한다. 해당 주제의 행성 우선순위, 신년 월별 근거, 궁합 상대방 차트/각도를 내부 설계에 포함한다. 상대방 별자리는 상대방 차트와 비교하며 본인 차트와 혼동하지 않는다. 보이지 않던 설계 키워드 UI를 추가하지 않는다.
8. 타로는 지정된 여덟 개 리포트 섹션에 필요한 최소 구조와 실제 선택 카드 확인을 유지·강화한다. 카드 수를 넘어 임의 월운이나 10년 예측을 생성하지 않는다.
