# 전 카테고리 상담 말투 적용 — 2026-11-01

## 적용한 내용

운영에 배포된 비교 시안(e0a9284)의 짧고 직접적인 상담 말투를 무료·미리보기·유료·기존 PDF 생성 경로에 적용했다. 이 작업은 시범 스토리 엔진의 활성화 여부와 독립적으로 동작한다.

- 계산형 사주: 성향·직업·재물·관계·생활 관리·학습의 여섯 영역 × 다섯 실제 해석 축, 30개 장면 문장을 다시 집필했다. 계산된 축 선택과 나이·기혼 여부에 따른 분기는 유지한다.
- 인생총운: 승인된 비교 시안의 성향/직업/재물 문장을 해당 실제 근거 조합의 본문에 반영했다. 가상 입력의 특정 연도·대운·직업을 다른 사람에게 복사하지 않으며 시기 문단은 기존 계산 결과로 채운다.
- 사주 신년·주제별 9종·궁합·이름·자미두수: 공통 문장 생성 및 각 리포트 출력에 같은 문장 편집을 적용한다. 데이터·수치·근거·이름·띠를 임의로 바꾸지 않는다.
- 무료: 만세력·일일운세·베딕·마하보테·오늘의 타로·오늘의 점성술·출생차트, 부가 MBTI 비교까지 포함한다. 베딕/마하보테의 별도 계산 체계와 시간 미상 설명은 유지한다.
- 타로: 78장 고유 의미·정역방향·실제 자리 역할을 유지하면서 종합 문장의 설계 설명을 쉬운 말로 바꾸었다. 12개 상품 × 3/5/10장 모두 적용한다.
- 점성술: 12개 상품의 계산형 출력과 무료 일일/출생차트에 적용한다. 실제 행성·각도와 시간 미상 안내는 유지한다.
- AI: 한국어 사주/타로/점성술/자미두수/궁합/이름/PDF/질문 답변의 집필 지침에 공통 상담 문체를 전달한다. 기존 초안을 단순 윤문하지 않고, 계산 근거로 장 전체를 집필하도록 지시한다. 모든 문단에 명령형 조언을 붙이지 않으며 이해할 만한 설명을 먼저 쓴다.
- PDF: 기존 14개 상품에 공통 문장 편집을 적용하고, 계산형 사주 장면의 반복적인 이론 도입을 줄였다. 자미두수는 주성 해석 후 실제 배치를 설명한다. PDF/화면이 공유하는 새 사주 문장도 반영된다. 현재 별도 상품이 없는 타로·서양 점성술 PDF를 새로 추가한 작업은 아니다.

## 표현과 근거

명료한 결론과 생활 예시는 허용한다. 모든 문장에서 가능성 어미를 반복하지 않는다. 다만 없는 사건에 '그랬을 수 있다'만 붙여 실제 이력처럼 만들지 않는다. 일반적인 생활 예시는 별도의 사실/계산 근거로 재사용하지 않는다.

`ReadingVoice`는 지정된 표현만 고치는 문장 편집 모듈이다. 일반적인 '~수 있어요'를 일괄 삭제하지 않는다. HTML 속성·스크립트·스타일·코드 영역을 보존하며, 시간 미상·미계산·진료 안내와 불확실성 문장을 그대로 유지하는 검사를 추가했다. 의미의 타당성을 보장하는 AI 판정기로 표방하지 않는다.

이전 시범 작업 파일(interpretation-engine/adapters/story.css 등)은 보존한다. 시범 기능은 기본 비활성 상태이며, 이번 상담 문체 적용은 기본 활성 경로다.

## 검증 범위와 운영 상태

실제 유료 AI를 호출하거나 실제 결제·이메일 발송을 하지 않았다. 따라서 새 지침으로 생성되는 실제 모델 문체·의미적 근거 일치·비용·응답 시간은 미검증이다. 모델의 문장 전체가 근거에서 논리적으로 도출되는지 정규식만으로 보장하지 않는다.

위 결과는 배포 전 로컬 구현/검증 기록이다. 운영 적용 시 프런트엔드 자산과 AI Worker를 함께 반영해야 한다. 무료 카테고리를 AI 방식으로 바꾸는 설정은 없다. 실제 배포 버전과 운영 파일 일치는 별도 배포 확인 결과를 기준으로 한다.
