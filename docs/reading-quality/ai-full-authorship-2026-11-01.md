# 무료 계산형 / 유료·PDF AI 전체 집필

## 적용 범위와 상태

사용자 확정 정책: **무료는 계산형, 유료/PDF는 AI 전체 집필**.
현재 변경은 로컬 작업 상태이며 이 작업에서 운영 배포는 하지 않았다.

- 무료 및 결제 전 미리보기: 기존 계산형 유지. 모델·인물 생성·번역 추론 호출 0건 검증.
- 사주 인생총운·신년·9개 주제, 궁합, 이름, 자미두수: 유료 해석 본문 전체를 새 AI 집필 경로로 교체.
- 유료 타로·서양 점성술: 기존 전체 AI 집필을 유지하며, AI 실패 때 계산형 완성본을 대신 표시하던 경로 제거.
- 기존 별도 PDF 14종: 소제목 본문·요약·월/분기 설명 모두 AI 집필. 실패한 칸을 계산형 문장으로 채우지 않는다.
- 원국·카드 추출·천체 위치·명반 계산, 제품/가격/결제는 유지. 도표·수치·정보 표는 계산 원본이고 해석 산문과 구분한다.
- 기존에 보관된 타로/점성술 보고서는 강제로 삭제하거나 재작성하지 않는다. 새 작성 및 재작성부터 새 실패 처리 적용.

## 변경한 구조

`assets/ai-report.js`를 추가했다. 실제 계산 결과를 근거 장부로 만들고 다음 순서로 처리한다.

1. 일간·월지 계절·지장간·실제 관계·신살·대운·세운·대표 월운 자료 수집.
2. 상품별 서로 다른 질문과 목차 선택.
3. 자기인식/원인 추적/전환점/선택 비교/궁 연결 등 주 서사 선택. 상충 서사는 실제 충·형·해·원진 신호가 있을 때만 추가.
4. AI가 전체 주제, 장별 결론과 근거 배정, 공통 근거가 있는 장 사이의 발전 관계를 설계.
5. 장별 AI 집필. 실제 근거 → 작용 이유 → 생활 모습 → 달라지는 조건 → 판단 기준을 본문 안에서 설명.
6. 근거 ID, 원국 글자 주장, 연도, 월별 누락, 인과 설명, 중복 문장, 알려지지 않은 과거 사건 단정 등을 검사.
7. 통과한 장만 캐시. 실패한 장만 재집필. 전체가 완성되어야 유료 본문 공개.

검증용 근거와 장 간 연결은 내부 데이터로 유지하며, 고객 화면에는 별도 ‘사주 근거 보기’ 상자를 생성하지 않는다. 유료 본문을 바꿀 때 기존 채팅 DOM과 관련 버튼, 원국·명반·계산 도표는 보존한다. 허구의 인물 생년·초성을 확인된 사실처럼 재사용하지 않는다.

PDF는 기존 A4 템플릿을 유지한다. PDF 전용 상세 본문을 전체 계획 아래 집필하고, 표지·요약·도표의 해석 칸도 AI 본문과 근거에 맞춰 AI가 작성한다. 예전 계산형 화면 산문을 부록으로 재삽입하지 않는다. 월/분기 상세 부록도 새 AI 본문이다. 전체 58,000자 상한은 유지한다.

## 변경 파일

- `assets/ai-report.js`: 근거 장부, 상품 목차/서사 선택, 전체 계획·장 집필, 검증·부분 캐시·재시도, 유료 렌더링.
- `worker/saju-chat-worker.js`: 기존 유료 `/reading` 안에서 새 계획/장/요약 JSON 프로토콜 처리. 인증과 공급자·모델 설정 유지.
- `index.html`: 새 모듈 연결, 사주 계열 유료 hydration 전환, 타로 실패 처리, 공통 ‘풀이 중입니다’ 대기.
- `assets/astrology.js`: 유료 AI 실패 재시도와 저장/복원, 오래된 비동기 응답 혼입 방지.
- `assets/report-pdf.js`: AI 전용 전체 집필·요약 경로, 미완성 PDF 생성 중단, 본문 출처 표시.
- `assets/reading-flow.css`: 본문 완성 전 공통 대기 화면.
- `tools/ai-full-report-regression.js`, `tools/ai-full-report-browser.js`, `tools/lib/ai-report-model-fixture.js`: 새 경로 검증.
- 기존 런타임/여정/심화/문체 테스트 및 `package.json`: 새 정책에 맞춘 검증 연결.

## 검증

모든 외부 AI 응답은 모의 응답이다. 실제 결제·모델·이메일 호출을 하지 않았다.

- 새 통합 테스트: 유료 14종 + PDF 14종의 전체 집필 경로, 계획/장 근거, 월별 배정, 잘못된 근거 재작성, 완성 캐시, 실패한 장만 재시도, 계산형 본문 대체 금지, 채팅 보존.
- `AI_REPORT_FULL=1 node tools/free-ai-regression.js`: 무료/미리보기 23개 경로에서 추론 0건. 유료 대조군만 모의 요청 발생.
- 실제 Chrome: 14종 × 모바일 390px/데스크톱 1069px = 28개 화면. 가로 넘침·실행 오류 없음.
- 실제 Chrome A4 레이아웃: AI 모의 본문으로 기존 PDF 14종 총 282쪽. 본문 넘침 없음, 모두 58,000자 이하. 인생총운·신년·이름·자미두수 PDF 파일 출력 및 대표 페이지 시각 확인.
- 기존 HEAD와 함수 본문 비교: 원국·대운·궁합·자미두수·스프레드·천체 계산 및 점성술 결제 완료 등 14개 함수 동일.
- 전체 `npm test` 통과. 이후 공통 사실 검증 보강은 새 통합 테스트와 무료 AI 차단 테스트를 다시 실행해 확인했다.

모의 글은 배관/배치 검사용이며 고객용 문장 품질의 예시가 아니다. 실제 공급자가 새 프롬프트로 작성한 한국어의 자연스러움·전문성·해석 깊이는 아직 실제 모델 샘플로 검수하지 않았다.

## 운영 및 한계

- Pages와 Worker를 함께 반영해야 한다. 새 프런트만 먼저 배포하면 기존 Worker는 새 응답 형식을 만들지 못하므로 재시도 화면이 나온다.
- `AIReportConfig.enabled` 기본값은 true. false는 사주 계열 기존 경로 비교/롤백용이다. PDF의 `skipAI:true`는 명시적인 오프라인 레이아웃 테스트 옵션이며 일반 다운로드 UI에서 사용하지 않는다.
- 유료 AI 요청량이 증가한다. 웹은 전체 계획 1회와 장별 묶음, PDF는 상세 장과 요약 묶음을 추가 요청한다. 성공한 장/칸의 부분 캐시와 동시 요청 2개로 재요청을 줄인다. 공급자 호출의 실제 금액·지연은 이 검사로 측정하지 않았다.
- 기존 신강약/용신은 개수·비율 참고값이다. 이를 종합 월령·통근 판정처럼 AI에 주지 않는다. 정밀 용신·격국 엔진을 새로 구현한 것은 아니다.
- 월운은 기존 계산기의 매월 대표일 기준이다. 정확한 절입 시각/일자 예언을 생성하지 않는다.
- 자미두수는 기존 간이 14주성 명반이다. 유년·유월·완전한 삼방사정/보조성 체계가 추가된 것은 아니다. 출생시각 미상 명반은 임시 기준임을 명시한다.
- 자동 검사는 근거 참조·일부 명시적 사실·구조/중복 오류를 탐지한다. 모든 자연어 결론이 근거로부터 논리적으로 도출되는지나 점술의 적중을 증명하지 않는다. 실제 AI 샘플 검수와 운영 관찰이 필요하다.
