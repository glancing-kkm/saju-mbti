# Claude 풀이 변경 이후 AI 종합 풀이 개편

작성일: 2026-10-29
상태: Claude 최종 커밋 81fbadd 검토 후 구현 및 회귀 검증. 운영 배포 전.

## 인수 기준

- 검토 시작 HEAD: 21bec87. index.html에 미커밋 변경이 있으며 지난 시기 해석과 성향 훅 변경을 확인했다.
- Claude 완료 후 git diff와 최종 커밋을 다시 확인한다. 기존 변경을 되돌리거나 같은 내용을 중복 구현하지 않는다.
- 기존 테스트는 구조와 생성 오류를 검증한다. 실제 출력의 명리적 일관성과 독자 관점 완성도는 별도로 검토한다.

## 개편할 역할

1. 코드: 원국, 절기, 시간 보정, 대운 시작, 대상 연도와 월운 등 계산 사실.
2. 해석 근거: 월령, 강약 판단, 지장간, 십신의 위치와 관계, 합충형파해, 격국·용신 판단 기준 및 한계.
3. AI: 근거의 우선순위, 상반되는 신호의 설명, 원국과 대운·세운·월운의 종합, 나이와 실제 상황에 맞춘 본문.
4. 검증: 계산에 없는 글자·시기 생성, 장 사이 모순, 잘못된 관계 상태, 반복, 근거 없는 과거 사건 단정을 차단한다.

가장 적은 오행을 용신으로 정하는 기존 getYongsin(oh) 결과를 확정적인 종합 판단으로 전달하지 않는다. 대체 판단 규칙은 명시하고 경계 사례를 검증한다. AI가 계산값을 임의로 고치게 하지 않는다.

## 문체

- 본문은 상담하듯 자연스러운 존댓말. 말풍선은 기존 도령 말투 유지.
- 모든 문단을 동일한 결론/이유/행동 문구로 시작하지 않는다. 분량을 채우는 일반론, 반복 비유, 추상적인 응원은 줄인다.
- 결론 → 구체적인 원국 근거 → 강점과 부담이 갈리는 조건 → 운의 변화 → 상황에 맞는 선택이 자연스럽게 이어지게 한다.
- 전문용어는 설명과 함께 사용한다. 용어를 늘어놓는 것으로 전문성을 대신하지 않는다.
- 계산된 경향, 사용자에게 직접 들은 사실, 아직 확인하지 못한 상황을 구분한다. 들은 사실을 사주로 알아맞힌 것처럼 표현하지 않는다.
- 과거 사건, 상대의 속마음, 임신·질병·수익을 확정하지 않는다. 구체성은 근거와 조건을 명확히 하는 데서 얻는다.
- 기존 preventOrphan, 줄 간격, 본문 크기, 접근성 유지.

## 데이터 연결 및 회귀 검증

- 공통 프로필과 카테고리별 상담 정보를 분리해 저장한다. 카테고리 간 이동 시 공통 정보는 유지하고 해당 상담 정보만 복원한다.
- 상충되는 선택(기혼과 솔로 등)은 자동 추측 대신 선택을 수정하도록 표시한다.
- 전달 경로: 입력 → 메타데이터 → 서버 검증 → 구조화된 AI 입력 → 본문 → PDF.
- 기존 birth 정보와 상담 정보, 계산 근거를 분리한다. 질문 변경 시 기존 AI 캐시와 혼동하지 않도록 상담 정보·계산 버전·프롬프트 버전을 캐시 키에 포함한다.
- 결제와 권한 확인 후 생성한다. 웹·PDF는 같은 검증된 원문을 사용한다. 실패 시 계산형 풀이를 AI 풀이로 표시하지 않는다.
- 새 입력의 저장/복원/수정, 실제 AI 전달 여부, 캐시 무효화, PDF 반영을 확인한다.
- 명리 검토자가 확인한 사례로 서로 다른 원국·혼인 상태·나이·시각 미상·절기 경계·연도 변경 사례를 평가한다.
- 인생총운·신년운세부터 실제 생성물을 기존 결과와 비교한다. 근거 일치, 종합성, 구체성, 반복, 자연스러운 문체와 비용·대기 시간을 보고 확대한다.

## 이번 구현과 검증 범위

- Claude의 과거 사건 규칙은 사용자 한 명의 과거 사건에 맞춘 고정 테스트가 있었다. 사건 단정표와 이 표본에 맞춘 순위 규칙을 제거했다.
- 과거 카드는 실제 천간·지지 관계를 최근 세 해까지 표시한다. 사건 발생 여부, 적중률, 미래 신뢰도를 뜻하지 않는다.
- 사용자 진술과 계산 근거를 별도 필드로 보낸다. 웹·PDF·질문 응답에 진술 출처를 밝히고 과거 단정을 하지 않도록 지시한다.
- 16개 사주 카테고리에 선택 상담 필드를 추가했다. 출생정보·카테고리별 세션 저장/복원, AI 및 PDF 전달, 상담 변경과 비동기 응답 도착 시 캐시 격리를 검증한다.
- AI에 원국 자리별 십신·지장간·글자 관계·신살 위치·계절을 전달한다. 기존 용신과 강약의 단순 계산은 종합 판정이 아닌 참고값으로 표시한다. 새로운 명리 판단 공식을 검증 없이 도입하지 않았다.
- 결제 후 장별 종합 모드는 검증된 계산 참조가 두 개 이상 포함되고 기존 문장 품질 검사를 통과한 응답에 한해 장 설명을 대체한다. 계산표·기간별 행·근거 접힘·세 강점 순서는 보존한다. 실패하면 기존 계산형 설명을 유지한다.
- 구문 검사는 의미의 정확성이나 미래 예측 정확도를 보장하지 않는다. 실제 모델 출력의 명리 전문가 검토, 비용/지연 측정은 별도 운영 검증 대상이다.
- 배포 시 Pages와 saju-chat Worker를 함께 반영해야 한다. 기존 AI/PDF 캐시는 버전 변경으로 재사용하지 않는다.
