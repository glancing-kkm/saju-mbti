## 계산형 풀이를 채운 방법

1. 원국의 실제 글자와 자리를 `natal.year.stem` 같은 근거 ID로 보관한다. 시각 미상에서는 시주 근거를 만들지 않는다.
2. 가장 두터운 성향과 보조 성향을 함께 읽는다. 수가 같으면 한쪽만 강하다고 단정하지 않는다.
3. 해당 연도·월의 천간과 지지, 실제 영역 점수, 자리 관계, 현재 대운을 연결한다. 월 번호나 이름을 바꿔 문구만 달라지게 하지 않는다.
4. 나이와 관계 상태에 맞춰 장면을 바꾼다. 어린이에게 취업·대출 조언을 붙이지 않고, 기혼자의 관계는 배우자와 생활 기준으로 읽는다.
5. 일·돈·관계·건강·공부는 보조 성향과 생애주기를 각 영역의 상황으로 풀어낸다. 총론을 모든 장에 그대로 붙이는 방식을 줄였다.
6. AI에도 같은 구조화 자료를 전달하되 허용 필드만 받는다. 너무 짧거나 중복된 보완, 원문에 없는 연도 추가 등은 화면 원문을 지우지 못한다. 이 검사는 의미상 모든 오류를 잡는 판정기는 아니다.
7. PDF는 같은 장의 문맥을 유지한다. 궁합·이름·자미두수를 개인 사주의 일반 성향으로 대체하지 않는다. 분기별 칸은 실제 월 점수와 실행·조절할 달로 채운다.

원국·운세 점수의 기존 산식, 상품 가격과 결제 정책을 바꾸는 작업은 포함하지 않았다.

## 남은 교열 지표와 한계

기존 본문과 새 설명을 합치면 50자 초과 문장 출현이 **2094건** 남는다. 같은 보고서에서 25자 이상 문장이 3회 이상 나오는 표본도 **286개**다. 반복 출현 초과분은 수정 전 2316건에서 수정 후 6402건이다. 설명을 늘리면서 공통 계산 근거와 기간별 행동도 반복되므로, **반복감이 모두 해결됐다고 판정하지 않는다**. 표현만 다르게 바꿔 이 수치를 낮추지도 않는다.

다음 교열에서는 월별·연도별 표와 본문에 중복된 동일 사실을 한 곳에서 설명하고, 이름·자미두수의 반복 안내와 긴 근거 문장을 우선 검토하는 것이 좋다. 같은 계산 조건에 같은 조언이 나오는 것은 유지하되, 독자가 같은 보고서를 읽는 동안 같은 이유를 여러 번 읽어야 하는지는 따로 판단해야 한다.

문장 길이·반복 지표는 `.lv4-sec`의 문단을 대상으로 한다. 무료 화면·타로·점성술의 모든 텍스트 노드를 같은 기준으로 교열했다고 해석하면 안 된다. 이 경로들은 생성 여부와 미치환 값, 관련 회귀 검사를 확인했다. AI 실응답의 말투·논리·사실성은 실제 출력 표본에 대한 별도 검토가 필요하다. 이 작업은 미래 예측의 경험적 정확성을 검증하지 않았다.
